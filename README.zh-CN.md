# Open Research (`open-research`)

[English](./README.md) | 简体中文

一个**完全独立自包含、跨领域、跨语言、带严格时效审计**的通用深度研究 Agent Skill。

`open-research` 将**多平台跨语言检索**、**GitHub 与行业深度调研**以及**信息时效性评估（Source Freshness）**三套方法论完整融合进单个工作流中——不局限于 AI 或软件测试，无论是**写学术论文、做行业与政策调研、评估开源项目，还是日常复杂问题全网求证**，都可以开箱即用。

---

## 为什么需要 `open-research`？

普通的大模型联网搜索通常存在四个致命盲区：
1. **单一语言信息茧房** —— 只按用户提问的语言或字面直译搜索，漏掉英文原版论文或本地一手政策。
2. **证实偏差（只报喜不报忧）** —— 只看排名前几的正面介绍，不主动排查撤稿记录、反面批评、兼容性破坏（Breaking Changes）或项目停更。
3. **洗稿同源幻觉** —— 看到五篇自媒体转述同一篇通稿，就误以为有“五个独立来源交叉印证”。
4. **时间盲区** —— 把两年前过时的 API 文档、早已无人维护的高 Star 仓库、或已被推翻的旧研究当成当前事实。

`open-research` 用一套可执行的闭环规则系统性解决这四个问题。

## 核心特性

- **全场景通用，四大核心模式**：
  - **学术与论文写作**：检索论文原件、追踪引文脉络、排查撤稿与复现失败、梳理学界共识与方法论争议。
  - **行业与市场调研**：跨地区对比（北美、欧洲、中国/亚洲等）、监管文件、财报数据与产业链格局。
  - **GitHub 与开源技术评估**：不只看 Star 和最近一次 Commit，强制核验 Releases、依赖清单、Issue 响应健康度、兼容性与开源协议。
  - **日常深度检索与求证**：消费/工具选型对比、政策细则核查、历史考据与多方争议梳理。
- **三档自适应深度**：
  - `Quick`（快速档：3–5 次搜索，覆盖 2+ 类来源）
  - `Standard`（标准档，默认：8–15 次搜索，覆盖 4+ 类来源，双语/多语言互搜 + 独立交叉验证）
  - `Deep`（深度档：6+ 类来源，拆分子问题并行检索，支持长文原子级事实核查）
- **四维查询扩展**：跨语言专业术语互搜 + 行业同义词扩展 + 多视角切换（定义/实操/案例/数据）+ **强制反面检索**（专门搜局限、批评、撤稿、停更、争议）。
- **内置时效性审计引擎**：严格区分**事件发生日**、**来源发布/更新日**与**访问日**，按领域波动周期标注 `[Current]`、`[Aging]`、`[Stale]` 或 `[Unknown]`。
- **证据分级与防洗稿溯源**：强制区分 `[Fact]`（事实）、`[Interpretation]`（解读）与 `[Recommendation]`（建议）；识别同源洗稿，标注 `[Single Source]`（单一来源）与 `[Vendor/Commercial Interest]`（商业利益相关）；未证实的社媒帖子单独隔离在**未证实线索**。
- **防提示词注入 + 高可读性排版**：所有网页和仓库内容一律视为不可信数据；默认跟随用户提问语言输出（外文资料保留原标题 + 链接），采用**结论先行、短句短段落、紧凑小表格（单表不超过 4–5 行）**的易读结构。

## 工作流概览

```text
用户提问
   │
   ▼
1. 界定问题与声明档位 (Quick / Standard / Deep)
   │
   ▼
2. 多来源跨语言检索 (8 大来源类型 + 跨地区覆盖)
   │
   ├──► 对抗性反面检索 (局限 / 批评 / 撤稿 / 破坏性更新)
   └──► GitHub 专项审计 (Releases / 依赖兼容性 / 维护状态 / License)
   │
   ▼
3. 时效性审计 (事件日 vs. 更新日 vs. 访问日 → Current / Aging / Stale / Unknown)
   │
   ▼
4. 交叉验证与证据分级 (溯源去重 + 区分 事实 / 解读 / 建议)
   │
   ▼
5. 高可读性输出 (截至 YYYY-MM-DD 结论 + 核心要点 + 盲区说明 + 来源清单)
```

## 安装方式

`open-research` 采用通用的 `SKILL.md` 标准编写，**完全零外部依赖**，单文件即可运行。

将本仓库克隆下来，或直接把 `SKILL.md` 复制到你使用的 Agent 技能目录中：

```bash
# Codex 个人技能目录
mkdir -p ~/.codex/skills/open-research
cp SKILL.md ~/.codex/skills/open-research/SKILL.md

# Comate 个人技能目录
mkdir -p ~/.comate/skills/open-research
cp SKILL.md ~/.comate/skills/open-research/SKILL.md

# Claude Code 个人技能目录
mkdir -p ~/.claude/skills/open-research
cp SKILL.md ~/.claude/skills/open-research/SKILL.md
```

*(Windows PowerShell 用户直接将 `SKILL.md` 放入 `$HOME\.codex\skills\open-research\` 或 `$HOME\.comate\skills\open-research\` 即可。)*

## 使用示例

- **写论文 / 文献综述**：
  > “我正在写一篇关于『微塑料对人体心血管系统影响』的综述论文，帮我深入调研一下 2024–2026 年最核心的临床研究进展、学界共识以及方法学上的主要争议。”
- **跨国行业与政策调研**：
  > “帮我调研一下目前美国、欧盟、中国、日本对『钠离子电池储能商业化』的政策支持、头部量产进度和成本瓶颈。”
- **开源项目选型与日常复杂搜索**：
  > “我想把家里几万张老照片做本地自托管管理（支持人脸识别、不上传云端），帮我全网对比目前最活跃的 GitHub 开源方案，看看近期维护状态、避坑点和硬件门槛。”
- **日常快速核查**：
  > “简单查一下：现在欧洲旅客来中国的过境免签时长是多少小时？政策最近一次更新是什么时候？”
